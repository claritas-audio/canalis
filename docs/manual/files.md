# Where things live

Where Canalis keeps its settings, its catalogue of plugins, the service and its logs.

## Settings

`~/.config/canalis/config.toml` holds devices, links, app targets, chains with their slots
(plugin state included), scenes and controls.

- Names only, never ids, so it survives a PipeWire restart.
- A file from any older Canalis is upgraded on load.
- If the file cannot be read, or a newer Canalis wrote it, it is left alone and nothing is
  saved until you choose in the banner at the top of the window. A copy is kept next to it
  either way.

## Plugin catalogue

`~/.cache/canalis/plugins.toml` is the plugin catalogue as last scanned. Delete it to force
a full rescan.

## Window preferences

`~/.config/canalis/gui.toml` holds the window's own preferences, today the interface
language. Without it Canalis follows the desktop's language.

## Graph layout

`~/.local/state/canalis/graph.toml` holds the Graph's camera and box positions. Delete it
for a fresh layout.

## The service

- The unit is `~/.config/systemd/user/canalis.service`, written when a window first starts
  it and rewritten if the Canalis binary moves.
- It listens on `$XDG_RUNTIME_DIR/canalis/canalis.sock`.
- Without systemd it runs as a plain background process logging to `service.log` next to
  that socket.

## Logs

- On a terminal: `RUST_LOG=canalis=info canalis`.
- The service logs to `journalctl --user -u canalis`.
